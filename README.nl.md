# Dierenstratego

[English](README.md) | [中文](README.zh-CN.md) | **Nederlands**

Een overblijfsel van een oude huiswerkopdracht. De volgende dag bedacht ik ineens dat ik het net zo goed op GitHub kon zetten en er misschien een paar stars mee kon verzamelen. Dus, hier is het.

Omdat ik destijds zowel lui als nogal een beginner was, heb ik de code niet netjes over meerdere bestanden verdeeld. De code zelf is ook niet bepaald prachtig geschreven. Maar goed, hij werkt tenminste.

## Geïmplementeerd

- Weergave van de speelstukken
- Verplaatsen van stukken
- Slaan van stukken
- Detecteren van een overwinning

## Nog niet geïmplementeerd, maar wel mogelijk

- Rivieren

## Nog niet geïmplementeerd, en waarschijnlijk niet door mij

- Een mooiere achtergrond

Voor het verplaatsen van de stukken gebruikte ik het wissen van de canvas. Daardoor is een goede achtergrond nogal lastig, tenzij de achtergrondafbeelding buiten de canvas wordt geplaatst. Destijds wist ik ook niet echt hoe ik met lagen moest werken, dus daar hield het idee ongeveer op.

## Voor wie kan dit nuttig zijn?

- Iemand die een eenvoudige webversie van Dierenstratego wil maken
- Iemand die wil zien hoe de basislogica van Dierenstratego kan worden geïmplementeerd
- Beginners met JavaScript
